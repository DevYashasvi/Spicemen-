⚡ Math Blitz
=============

A fast-paced, interactive math challenge web app where you solve math problems as quickly as possible!

## 🎮 Features

- **Multiple Difficulty Levels**: Easy, Medium, and Hard
- **Flexible Time Limits**: Choose 30, 60, or 90 seconds
- **Score Tracking**: Earn points based on difficulty and speed
- **Streak Counter**: Track your consecutive correct answers
- **Accuracy Metrics**: See your performance statistics
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Beautiful UI**: Modern gradient design with smooth animations

## 🎯 How to Play

1. **Select Difficulty**: Choose between Easy, Medium, or Hard
   - Easy: Numbers 1-10, Addition & Subtraction
   - Medium: Numbers 1-50, Addition, Subtraction & Multiplication
   - Hard: Numbers 1-100, All operations including Division

2. **Choose Time Limit**: Pick 30, 60, or 90 seconds

3. **Solve Problems**: Answer as many math problems as you can before time runs out

4. **Check Results**: See your final score, accuracy, and best streak

## 🚀 Deployment

This app is deployed on GitHub Pages and can be accessed at:
[https://DevYashasvi.github.io/Spicemen-](https://DevYashasvi.github.io/Spicemen-)

### To Deploy to Your Own GitHub Pages:

1. Fork or clone this repository
2. Go to **Settings → Pages**
3. Select **Deploy from a branch**
4. Choose **main** branch and **/(root)** folder
5. Click **Save**

Your app will be live at: `https://[YOUR-USERNAME].github.io/Spicemen-`

## 🔧 Customization

You can easily customize the game by editing:

- **Difficulty ranges**: Edit `difficultyConfig` in `script.js`
- **Colors**: Modify CSS variables in `styles.css` under `:root`
- **Points system**: Adjust scoring in `submitAnswer()` function
- **Operations**: Add new math operations in `generateQuestion()`

## 🐛 Troubleshooting

### Game not loading?
- Clear your browser cache
- Try a different browser
- Check your internet connection

### Page not deploying?
- Ensure repository is public
- GitHub Pages is enabled in settings
- Branch is set to `main` and folder is `/(root)`
